# 测试运行入口

本文件只维护实际测试代码的组织、环境、夹具和可运行命令。选测、三阶段验证、隔离、失败处理和证据要求统一见 [docs 下的测试规范与设计入口](../docs/测试/README.md)，不在此复制。

## 当前可用情况

仓库尚无产品源码、测试用例、依赖配置或测试执行脚本，因此当前没有可登记的产品测试命令，也没有已验证的项目测试环境。本说明不判断本机是否安装了 Python 等工具。

文档检查使用文件工具和一次性只读检查，结果记录在对应方案中；只读审查见交付摘要，不能作为产品测试通过记录。确需独立测试报告时按 docs 下的测试规范建立。

## 测试实现落地时维护

对应实施方案建立测试时，同步在本文件登记：

1. 实际目录和覆盖的模块；按需要采用 unit、integration、contract、recovery、e2e，不先建空目录。
2. 安装依赖、解释器/工具版本、工作目录、必需配置和启动前提。
3. 可以复制执行的命令、适用测试范围、预期退出/结果及证据输出位置；真实平台命令单独注明账号和操作前提。
4. 可提交的合成或脱敏夹具、仓外测试轮次位置、可控时钟及 Fake Adapter 的实际用法。
5. 启停、清理方式和已知环境限制；只登记已经存在并验证过的入口。

根 README 链接本文件，不重复维护另一套测试命令。后续内容过长时，可将分域运行说明放入对应测试子目录并由此导航；长期测试方法仍归 `docs/测试/`。
