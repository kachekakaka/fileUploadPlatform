# 文件上传平台

目标是独立运行的上传应用，提供 REST API、Python SDK、CLI 和 Web Dashboard，首批支持 Bilibili 与百度网盘。

当前已建立项目约束与长期文档体系，包括需求、设计、待办、实施方案管理和测试规范；尚无产品源码、可运行服务或测试实现。初始任务书和用户提供的 rc2 资料供追溯、编写方案参考，不表示目标功能已交付。

## 文件存放约定

| 位置 | 用途与边界 |
| --- | --- |
| 本仓库 | 源码（后续实现）、工程配置、长期文档及经审查的合成或脱敏最小样本 |
| `依据/` | 只保存初始任务书 Markdown 和原始 ZIP；编写方案时按需参考 |
| `archive/` | 已完成方案、讨论记录等历史文档 |
| `../fileUploadPlatform_datas/` | 后续运行配置、凭据、数据库、平台接收的文件、备份和长期私有材料；不进入 Git |
| `../fileUploadPlatform_tmp/` | 后续测试轮次、临时脚本、完整日志、截图及可重建中间产物；不进入 Git |
| 调用方原文件所在位置 | 本地成片原件；平台引用不等于取得移动、覆盖或删除权限 |

上述仓外目录为存放约定，本轮不创建运行目录，也不搬迁运行数据。真实失败现场、凭据及唯一原件不能只因放在 tmp 中就被删除；清理须核对归属、用途和现有授权。部署目录和容器挂载随后续部署文档明确，不硬编码这台机器的路径到产品实现中。
