# 文件交接采用本地引用与网页接收，不额外扫描内容

用户在文件交接讨论中选择 A：录制或剪辑工具已经生成的本机成品文件，由上传平台直接引用，默认不再复制到平台自己的素材目录。与平台另存副本相比，这减少大文件复制时间和额外磁盘占用；代价是提交方必须保留原文件到任务结束，上传任务依赖原件仍然可用。

用户进一步确认：本地视频执行时直接读取指定路径，不进行提交前后文件变化比对，也不计算文件内容摘要。平台不保证上传内容仍是提交时的版本；文件不存在、读取失败或上传失败时，正常报告实际错误。此取舍避免为上传额外扫描大文件，不授权自动删除原文件。

对于其他电脑通过网页传入的文件，用户确认正常接收完成后即可供上传任务使用，不额外扫描文件内容或计算内容摘要，避免大文件接收后再等待一轮读取。接收中断、写入失败等实际错误正常处理；尚未完整接收的文件不能作为可用素材，也不能把接收完成当成目标平台上传成功。

现行业务要求由[需求说明 R02](../需求说明.md)维护，实现边界由[设计说明 D03](../设计说明.md)承接；初始任务书保留同步后的参考内容。本记录保留决定及取舍理由，不表示相关功能已经实现；原始资料按[根 README](../../README.md)说明按需参考，在具体方案采用相关内容时核对本决定。
