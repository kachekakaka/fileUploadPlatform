# B18 仅自己可见验收

本轮交付与验收覆盖 Core 和独立 B 站上传引擎。真实试投仅放行一份指定单 P，用新作品标识复用已确认的《雾海灯塔》素材，原作品与公开稿件保留。[集成方案](../../docs/方案/20261116-Bilibili集成与自维护方案-v1.2.md#2313-仅自己可见)

## 实施与验证

- Core 沿用必填的 `publish_mode`，校验引擎支持 `self_only`。专用清单绑定账号、构建、数据目录、一份作品及一个立即执行名额，创建任务和 Worker 交接时都重新核验。引擎明确将 `self_only` 映射为 `is_only_self=1`，公开为 0，未知值在联系平台前拒绝。空间列表隐藏独立映射。[设计说明](../../docs/设计说明.md) · [运行说明](../../docs/operations/bilibili.md#b18-受控投稿入口)
- 本地 Core 50 项、引擎 HTTP 上传 22 项通过。用实际 Core、Rust 引擎和回环测试服务核对私密与公开的投稿字段、两种选项的独立性、旧构建及未知值拒绝、清单范围与单次名额。Core 有一条既有的 Starlette 测试客户端弃用警告。
- 2026-11-19 00:33，以正式编译的候选引擎 `bue-0.2.0-dev4` 提交《雾海灯塔｜仅自己可见验证》一次。平台受理，两次独立查询核对同一账号、同一稿件和一个视频键，最近审核状态为 `-50`。一次性清单已撤下，专用 Server 和 Worker 已退出，日常 Core 照常运行。
- 创作中心标记「仅自己可见」。用投稿账号打开同一稿件，播放器已播放到 4 秒，整段 8 秒。未登录浏览器访问同一地址时，B 站提示稿件仅作者可见，页面没有播放器。用户另外用其他已登录账号复核，确认无法观看。

## 证据与后续

仓外证据目录为 `../fileUploadPlatform_tmp/self-only-20261119/`，相对于仓库根目录。包含本地测试日志和 JUnit XML、任务观察、两次独立查询和专用进程退出记录。私密试投的验收范围已完成。普通部署的发布能力继续由集成方案管理，个人空间投稿列表隐藏仍以本地模拟为验收边界。
